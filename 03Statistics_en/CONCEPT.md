# Statistics — 게임 컨셉 문서


---

## 1. 게임 개요

이 게임은 실제 설문조사·통계 데이터를 기반으로 한 오프라인 멀티플레이 파티 게임이다.  
플레이어들은 실생활 통계 수치를 퍼센트(%)로 추측하며, 얼마나 정확하게 맞히는지를 겨룬다.

- 별도의 서버, 인터넷 연결, 계정 없이 완전히 로컬에서 작동한다.
- 한 공간에 모인 여러 명이 각자의 기기로 동일한 게임을 플레이한다.
- 90%모바일로 플레이(브라우저) 10% PC브라우저로 플레이 할듯
---

## 2. 핵심 컨셉: 오프라인 멀티플레이

### 어떻게 서버 없이 멀티플레이를 구현하는가?

**4자리 게임 코드(시드)** 를 공유하는 방식으로 해결한다.

- 호스트가 4자리 알파벳 코드를 생성한다. (예: `BQRZ`)
- 이 코드가 난수 생성기의 시드(seed)로 사용된다.
- 같은 코드를 입력한 모든 기기는 완전히 동일한 문제 순서를 받는다.
- 실시간 통신 없이도 모든 플레이어가 같은 게임을 경험한다.

예시:
```
호스트 기기             참가자 기기
  "BQRZ" 생성    →   "BQRZ" 입력
       ↓                   ↓
  동일한 10문제 시퀀스 생성 (LCG 알고리즘)
       ↓                   ↓
  각자 독립적으로 플레이 (인터넷 불필요)
       ↓                   ↓
  오프라인 공간에서 결과를 직접 비교
```

**코드 규칙:**
- 알파벳 24자 사용 (I, L 제외 — 숫자 1, 0과의 혼동 방지)
- 24⁴ = 331,776가지 고유 게임 조합 가능
- 동일한 코드 → 항상 동일한 문제 순서 (재현 가능)

---

## 3. 게임 모드

### 3-1. Absolute Mode

플레이어가 통계 수치를 **정확한 퍼센트(0~100%)** 로 추측하는 모드.

- 예시 문제: *"18세 이후에도 인형을 안고 자는 사람은 몇 %일까?"*
- 정답: 46%
- 플레이어는 원형 슬라이더를 드래그하여 추측값을 입력한다.

### 3-2. Relative Mode

두 통계 중 어느 쪽이 더 높은지를 선택하는 상대 비교 모드.  
현재는 메인 메뉴에 "Coming Soon" 플레이스홀더만 존재한다.

---

## 4. 게임 플로우

```
[메인 메뉴] index.html
    │
    ├─ Absolute Mode 선택
    │       │
    │       ├─ [Host] 코드 생성 → 친구들에게 코드 공유
    │       └─ [Join] 코드 입력 (4자리)
    │               │
    │               ▼
    │       [게임 플레이] play.html  ← 10라운드 반복
    │               │
    │               ▼ (라운드마다)
    │       [대기 화면] standby.html  ← "탭해서 정답 확인"
    │               │
    │               ▼ (10라운드 완료)
    │       [결과 화면] gameover.html
    │
    └─ Relative Mode (미구현)
```

### 라운드 진행 (1라운드 기준)

1. **문제 표시** — 통계 질문 + 출처 표시
2. **추측 입력** — 원형 슬라이더로 0~100% 드래그
3. **제출** — 확인 모달 후 제출
4. **대기 화면** — 정답이 가려진 채로 화면 전환 (다른 플레이어가 제출 완료할 때까지 대기)
5. **정답 공개** — 탭하면 정답 + 내 추측 + 라운드 점수 표시
6. **다음 라운드** — 10라운드까지 반복

> **대기 화면의 역할:**  
> 인터넷 연결이 없으므로, 먼저 제출한 플레이어가 정답을 미리 보고 다른 플레이어에게 말해주는 상황을 방지한다.  
> 모든 플레이어가 제출 후 함께 "탭해서 공개"하는 방식으로 페어플레이를 유도한다.

---

## 5. 점수 계산

```
accuracy  = 100 - (|내 추측 - 정답| / 정답 × 100)
roundScore = accuracy²
```

- 정확할수록 기하급수적으로 높은 점수
- 10라운드 합산 최대 점수: 100,000점 (매 라운드 완벽할 경우)
- 총점은 gameover 화면에서 표시

**예시:**
| 정답 | 내 추측 | 오차 | 정확도 | 라운드 점수 |
|------|---------|------|--------|------------|
| 46%  | 50%     | 4%   | 91.3%  | ≈ 8,335점  |
| 84%  | 84%     | 0%   | 100%   | 10,000점   |
| 60%  | 30%     | 30%  | 50%    | 2,500점    |

## 6. 핵심 UI 컴포넌트

### 원형 슬라이더 (메인 입력 수단)
- 외곽 링을 드래그하여 값 조절


### 모달 확인 시스템
- 제출, 뒤로가기, 다음 라운드 등 중요한 행동 전에 확인 모달 표시
- 실수로 인한 진행 손실 방지

### 대기 화면
- "Tap to Reveal!" 텍스트로 정답을 가림
- 클릭/탭 시 정답, 내 추측, 점수 동시 공개
