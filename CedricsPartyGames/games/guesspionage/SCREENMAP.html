Full game flow
SETUP → CATEGORY (current player picks) → GUESS (slider 0–100) → CALL (Higher / Lower) → REVEAL → repeat × per_round turns (= min(players, 6)) for Round 1 → repeat × per_round turns for Round 2 (+ Much Higher/Lower if ≤5 players) → BONUS QUESTION (pick #1 answer) → BONUS REVEAL → END
Scoring quick reference
Guesser
Exact = 3,000 pts
Linear decay to 0 at 30% off
Shrug (50%) = 0 pts
Caller (Higher/Lower)
Correct direction = 1,000 pts
Wrong = 0 pts
Caller (Much — Round 2 only, ≤5p)
Correct + gap >15% = 2,000 pts
Otherwise = 0 pts
Bonus
Picked the #1 answer = 2,000 pts
Any other answer = 0 pts
