# PartyTheme

Root wrapper. Wrap every screen. It sets colors, fonts, radius and motion from the chosen theme.

```jsx
<PartyTheme theme="neon-jungle">
  <Screen variant="phone">…</Screen>
</PartyTheme>
```
Themes: cartoon-party (default), old-money, neon-jungle, hackers, arcade-80s, spooky-mansion, space, medieval, tropical-ocean, noir-detective, candy-pop, notebook-sketch, game-show. Pick one per game; never mix.
